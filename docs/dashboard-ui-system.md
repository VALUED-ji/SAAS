# 经营类 Dashboard UI 组件与设计规范

适用范围：集团总览、经营总览、经营分析、财务经营看板等以指标和图表为主的页面。

## 设计方向

- 风格关键词：干净、轻量、圆角、留白、经营数据突出。
- 参考语言：现代 SaaS Analytics Dashboard。
- 页面重点：先看业务状态，再看趋势，再看明细/排行。
- 禁止做法：大面积蓝色背景、厚重阴影、直角硬边框、密集 ERP 卡片、无意义装饰。

## 视觉 Token

| 类型 | Token | 色值 | 用途 |
| --- | --- | --- | --- |
| 页面底色 | `canvas` | `#FAFAF9` | Dashboard 背景 |
| 主卡片 | `panel` | `#FFFFFF` | 指标卡、图表卡、列表卡 |
| 次级底色 | `panelMuted` | `#F7F7F5` | 筛选控件、表头、空状态 |
| 线框 | `border` | `#ECEDEA` | 卡片和控件细边框 |
| 主文字 | `text` | `#171717` | 标题、关键数字 |
| 次文字 | `textMuted` | `#737373` | 说明、坐标轴 |
| 弱文字 | `textSubtle` | `#A3A3A3` | 辅助提示 |
| 成功/增长 | `green` | `#58C45D` | 增长、完成、主趋势线 |
| 待处理/对比 | `orange` | `#FF7A45` | 待处理、对比趋势线 |
| 警示/目标 | `amber` | `#DFA400` | 目标进度、注意状态 |
| 信息 | `blue` | `#407AFF` | 少量信息强调，不做大面积铺底 |

## 圆角与阴影

- 指标卡、图表卡：`18px`。
- 控件、图标按钮、日期筛选：`12px`。
- 进度条：`8px`。
- 状态标签：胶囊圆角。
- 阴影只用于轻微层级：`0 10px 30px rgba(23,23,23,0.025)`。
- Hover 可稍微增强，但不能变成漂浮卡片堆叠。

## 间距系统

- 页面外边距：桌面端 `28px`，普通桌面 `20px`，移动端 `16px`。
- 页面模块间距：`24px`。
- 卡片内边距：`20px`。
- 图表卡标题与内容间距：`20px`。
- 表格行高：不低于 `48px`。
- 控件高度：`44px`。

## 字体层级

- 页面标题：`30-34px / 600`，数字字距略收紧。
- 卡片标题：`15-17px / 600`。
- 指标数字：`34px / 600`，使用 `tabular-nums`。
- 正文说明：`13-14px / 500`。
- 辅助信息：`12px / 500`。

## 标准组件

源码位置：`src/components/dashboard/dashboard-system.tsx`

- `DashboardShell`：经营 Dashboard 页面壳。
- `DashboardHeader`：欢迎/页面标题区域。
- `DashboardCard`：图表、列表、排行的标准卡片。
- `MetricCard`：顶部核心指标卡。
- `DashboardControl`：时间筛选和普通按钮。
- `DashboardSelectShell` / `DashboardDateControl`：日期和下拉类控件。
- `LegendItem`：图表图例。
- `StatusPill`：表格/状态标签。
- `ProgressMetric`：目标或完成率进度。
- `DashboardEmpty`：空状态。

## 页面组合规则

1. Header：左侧页面标题和说明，右侧放时间筛选/关键操作。
2. KPI：首屏紧跟核心指标，数字优先，说明弱化。
3. 主图表：趋势图占更大宽度，对比图/来源图放右侧。
4. 明细/排行：放在图表后，用更紧凑列表展示。
5. 图表颜色：主线绿色，对比橙色，蓝色只少量用于信息状态。
6. 空状态：保留卡片结构，不出现大片空白。
7. 不为了 UI 新增假数据；所有数据必须来自现有接口或当前页面已有字段。

## 经营总览落地说明

- 本次升级只替换 UI 结构和视觉组件。
- 不修改 `/api/dashboard`。
- 不修改 Dashboard 数据结构。
- 不修改权限逻辑。
- 不新增导出、审批、财务等业务动作。

## 集团总览落地说明

- 集团总览复用同一套 Dashboard 组件、圆角、留白、颜色和控件规则。
- 不修改 `/api/group-dashboard`。
- 不修改集团总览数据结构。
- 不修改省份/大区切换、地图全屏、权限逻辑。
- 中国地图、客户漏斗、工地阶段、分公司排行只做视觉和布局升级。

## 客户管理列表落地说明

- 客户管理列表按资源工作台处理，复用 Dashboard 的页面底色、Header、卡片、控件、表格和浮层视觉规则。
- 不修改 `/api/customers`。
- 不修改客户列表数据结构、筛选参数、权限逻辑、列拖拽、导入导出、新增编辑、删除恢复和分页行为。
- 顶部动作放入 `DashboardHeader` 右侧，筛选区使用轻量分段控件、搜索框和可展开高级筛选。
- 表格使用低干扰表头、稳定行高、轻 hover 和 sticky 操作列，避免传统 ERP 的厚重蓝色和密集硬边框。
- 组织筛选下拉、重复客户弹窗、导入客户弹窗需要跟随同一套圆角、线框、阴影、loading 和空状态规范。

## 左侧菜单栏落地说明

- 左侧菜单栏是全系统主导航，使用轻量 SaaS 导航 rail 规则：白色主面板、`#ECEDEA` 分割线、`#F7F7F5` hover/active 底色。
- 蓝色只用于小面积位置提示：当前菜单左侧指示条、激活图标、少量焦点态，不做大面积铺底。
- 一级菜单保持 `44px` 最小高度，图标统一 `32px` 容器，文字使用 `14px / 500-650`。
- 二级菜单保留展开/收起动画，动画只使用高度网格、透明度和轻微位移，避免影响页面布局。
- 待办数量保留红色圆点徽标，位置在“待办中心”菜单右侧；收起时贴在图标右上角。
- 不修改菜单顺序、权限过滤、路由跳转、预加载、待办数量接口和账号退出逻辑。

## 全系统 UI v2 落地说明

- 全系统后台界面统一使用 `src/app/system-ui.css` 的 Token 与作用域，避免继续在历史全局样式末尾叠加零散补丁。
- 标准页面、面板、工具栏、空状态和弹窗框架位于 `src/components/ui/system-ui.tsx`，新开发页面必须优先复用。
- 统一规格：页面面板 `16px`、弹窗 `18px`、控件 `10px`、内部小元素 `8px`；状态标签保持胶囊形。
- 主色 `#407AFF` 只用于主操作、当前状态与焦点态；页面使用 `#F6F7F9`、`#FFFFFF`、`#FAFAF9` 三层中性表面。
- 列表、详情、设置和复杂编辑器按同一 Token 使用不同信息密度，不把所有业务界面强行做成相同卡片网格。
- 已升级保护范围：经营总览 `/dashboard`、集团总览 `/group-dashboard`、客户列表 `/projects`、左侧菜单栏；系统 UI v2 不重做这些页面。
- 独立体验不纳入后台通用作用域：登录页、报价分享、VR 分享、工地扫码签到、签名采集。
- 本轮只升级 UI 结构、视觉与交互状态，不修改 API、数据结构、权限、排序、默认值或业务流程。
